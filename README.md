This project developed a convolutional neural network (CNN) to classify animal images, comparing two approaches: a model built from scratch using residual blocks and a transfer-learning approach using a pretrained model with a custom residual block. The goal was to determine which modeling strategy could more effectively recognize animals from images while demonstrating how deep learning and residual networks can be applied to image classification.

From a business perspective, this type of image-classification system could support organizations such as wildlife monitoring groups, animal shelters, conservation organizations, or companies managing large image collections that need to categorize animal images efficiently. The stakeholder could be a data science or operations team deciding whether to build a vision model from scratch or use transfer learning with an existing pretrained model. Automating classification could reduce the time and manual effort required to review large numbers of images and allow staff to focus on higher-value analysis or decision-making.

The project supports the decision of which machine-learning approach is most practical for an animal image-recognition application. Comparing a custom CNN with a pretrained model helps stakeholders evaluate tradeoffs in model development, performance, and training effort. The broader takeaway is that image classification can turn unstructured image data into structured information that organizations can use for tasks such as species identification, image organization, population monitoring, or prioritizing images for further review.
